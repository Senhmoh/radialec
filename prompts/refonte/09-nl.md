Démarrée le 13/10/2026 à la demande du propriétaire (des clients écrivent en néerlandais). **En ligne depuis le 17/10/2026**, après relecture (accord du propriétaire) : `nlPublished = true` dans `app/data/visibility.ts`.

- toute adresse `/nl…` renvoie vers la 404 française, sauf `/nl/aanbod` (offre flyer) ;

## Entretien de la version néerlandaise

- **Quand un texte français change** (prix, promesse, nouvelle page), sa page néerlandaise doit suivre. Elle est dans `app/data/nl/` : mêmes faits, prix toujours via `pricing.ts`.
- **Nouvelle page française :** créer aussi sa version néerlandaise (même `category` / `slug`, adresse dans `path`). Pour une page fixe, l'ajouter à `translatedPages` (`lib/i18n/routes.ts`).
- **Avant chaque mise en ligne importante,** `npm run check:links` sur un serveur lancé ne doit trouver aucun lien cassé.
- **Textes à faire valider s'ils changent :**
  - les consignes gaz néerlandaises (`gasLeakAlertNl`, `app/data/safety.ts`), avec le gestionnaire ;
  - les pages légales, avec un juriste.

## Où est quoi (code)

- `app/(fr)/` et `app/(nl)/nl/` : une mise en page racine par langue ; les deux appellent `app/sections/v2/SiteShell.tsx`.
- `lib/i18n/` :
  - `locale.ts` : langues ;
  - `routes.ts` : adresses par langue, pages traduites ;
  - `server.ts` : `setRequestLocale` / `getRequestLocale` ;
  - `client.tsx` : `useLocale` ;
  - `ui.ts` : textes d'interface.
- Contenu néerlandais : `app/data/nl/`. Une page service néerlandaise garde la `category` et le `slug` de la page française (ses identifiants) ; son adresse est dans `path`.
- Gabarits partagés : `HomePage`, `ContactPage`, `QuotePage`, `BookingPage`, `CategoryPage`, `ServicePageV2`, `LegalPage`.
- Cal.com : l'agenda suit la langue du navigateur du visiteur. La réservation en ligne s'affiche « Ketelonderhoud » (`labelNl`).
