# Version néerlandaise du site (`/nl`)

Démarrée le 13/10/2026 à la demande du propriétaire (des clients écrivent en néerlandais). Le site néerlandais se construit par étapes et **reste invisible en production** tant qu'il n'est pas complet et relu : `nlPublished = false` dans `app/data/visibility.ts`. Il est visible avec `npm run dev` et sur un aperçu Vercel où `SHOW_DRAFTS=1`.

En production, tant qu'il est masqué : toute adresse `/nl…` affiche la 404 française (réécriture dans `next.config.ts`), pas de sélecteur de langue, pas de hreflang, rien dans le plan du site.

  - Pas de formules toutes faites : « één aanspreekpunt », « van A tot Z », « zorgeloos », « zonder verrassingen »…

## Où est quoi (code)

- `app/(fr)/` et `app/(nl)/nl/` : une mise en page racine par langue ; les deux appellent `app/sections/v2/SiteShell.tsx`.
- `lib/i18n/` :
  - `locale.ts` : langues ;
  - `routes.ts` : adresses par langue, pages traduites ;
  - `server.ts` : `setRequestLocale` / `getRequestLocale` ;
  - `client.tsx` : `useLocale` ;
  - `ui.ts` : textes d'interface.
- Contenu néerlandais : `app/data/nl/`. Une page service néerlandaise garde la `category` et le `slug` de la page française (ses identifiants) ; son adresse est dans `path`.
- Gabarits partagés : `HomePage`, `ContactPage`, `QuotePage`, `BookingPage`, `CategoryPage`, `ServicePageV2`, `LegalPage`.
- Cal.com : l'agenda suit la langue du navigateur du visiteur. La réservation en ligne s'affiche « Ketelonderhoud » (`labelNl`).
